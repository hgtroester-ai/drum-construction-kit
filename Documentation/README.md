# Drum Construction Kit 0.8.0 — Documentation files

These are the documentation and notice files included in the Drum Construction Kit 0.8.0 source package.

The artwork statements in `THIRD-PARTY-NOTICES.md`, `COPYRIGHT.md` and `RELEASE-CHECKLIST-0.8.0.md` have been updated to reflect the maintainer's confirmation that the HGT logo, banner and related visual elements are original HGT artwork created with AI assistance based on HGT's own descriptions and creative direction.

Upload the contents of this `Documentation` folder into a folder named `Documentation` in the `drum-construction-kit` GitHub repository. Then README links can point to `Documentation/FILENAME`. Keep the original copies in the source release package as well.
