## Artwork

The HGT logo, banner and related visual elements are original artwork created by HGT with AI assistance, based on HGT's own descriptions and creative direction. Their geometric visual language is inspired by Piet Mondrian.

## Audio Assets

The audio assets and their licensing information are documented in SOUND-ASSETS.md and SOUND-ASSET-MANIFEST.json. Please refer to these files for the applicable source and license details.

## Project

Drum Construction Kit is an independently developed Ableton Live extension by HGT.

For product information, features and downloads, see the [main project README](../README.md).
